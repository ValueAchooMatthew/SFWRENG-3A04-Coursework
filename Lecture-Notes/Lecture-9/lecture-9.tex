\begin{itemize}
	\item An architect is a person responsible for formulating the design of a system.
	\item An architect must always provide three things when designing a system for the design to be valid:
	\begin{enumerate}
		%TODO: Elaborate
		\item The system's elements.
		\item The system's connectors.
		\item The rationale behind the elements/connectors chosen.
	\end{enumerate}
	\item The component parts of a system, particularly its modules, should have minimal knowledge about one another.
	\item Structure graphs can have connectors with the following attributes:
	\begin{enumerate}
		%TODO: Elaborate
		\item Direction.
		\item Synchronization.
		\item Sequence.
	\end{enumerate}
	%TODO: Explain
	\item Connectors at a given level of a structure graph inherit attributes from their code-structure counterparts.
	\begin{itemize}
		\item For example, their multiplicity, their distance, and the medium over which the connection is performed.
	\end{itemize}
\end{itemize}
